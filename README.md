# Central de Estudos

## Sobre o projeto

A Central de Estudos é uma aplicação de terminal desenvolvida em Java para organizar disciplinas, registrar notas e acompanhar o desempenho acadêmico.

Este projeto foi criado como parte dos meus estudos iniciais em programação e orientação a objetos.

## Funcionalidades

- Cadastro de disciplinas.
- Registro de duas notas por disciplina.
- Cálculo automático da média.
- Verificação da situação acadêmica.
- Consulta de disciplinas cadastradas.
- Resumo geral do desempenho.
- Validação de entradas do usuário.
- Edição e excluisão de disciplinas
- Pesquisa de disciplinas pelo nome
- Salvamento dos dados para consultas futuras.

## Tecnologias utilizadas

- Java
- JDK
- Visual Studio Code
- Git e GitHub (para versionamento e publicação do código)

## Como executar

1. Instale o JDK.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Compile os arquivos:

   `javac Main.java Disciplina.java`

5. Execute o programa:

   `java Main`

## Regras do sistema

- Cada disciplina possui três notas.
- As notas devem estar entre 0 e 10.
- A média é calculada pela soma das notas dividida por dois.
- A média igual ou superior a 7,0 é considerada aprovada.
- Os dados permanecem em memória e são salvos após o encerramento.
